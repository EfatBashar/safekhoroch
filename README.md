# Safe Khoroch

Create a personal expense tracker app.



Features:

- Dashboard with total cash, account balance, income, and expense

- Add income and expense with amount, category, and date

- Transaction history list

- Debt and loan tracking (borrow and lend)

- Simple financial summary



UI:

- Clean mobile design

- Colored cards (green for income, red for expense, blue for balance)

- Bottom navigation (Dashboard, Transactions, Accounts, Loans)

- Floating add button (+)



Optional:

- Daily and monthly report

- Simple charts
